# Papers

Source PDFs for every published number cited in this project. Every value pulled from
a paper (bounds, table entries, figure readings) must trace to a file here — see the
"no numbers from memory" rule in `CLAUDE.md`.

Naming convention: `<arXiv ID>v<version>_<short-slug>.pdf`, e.g.
`2607.01226v2_intertwined.pdf`, `2410.00090v1_loverde-weiner.pdf`.
